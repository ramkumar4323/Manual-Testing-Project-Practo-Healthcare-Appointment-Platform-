## Practo Application – Manual Testing Project

**Project Overview**

This repository contains manual testing test scenarios and test cases written for a real-time healthcare application (Practo).
The test cases are designed by considering end-user behavior and cover Functional, Integration, System Testing.

## This project is created mainly for:

Manual Testing practice
Interview preparation
Understanding real-time healthcare workflows

## Scope of Testing

The following modules and features are covered in this project:
User Registration & Login
Doctor Search & Filters
Appointment Booking
Date & Time Slot Selection
Payment Flow
File Upload (Reports / Prescriptions)
Order & Medicine Delivery
Appointment History & Dashboard
Logout Functionality

## Types of Testing Covered

**Functional Testing**
Text Fields validation (Name, Email, Mobile, Password)
Dropdowns (Specialization, City, Time Slot)
Radio Buttons (Gender selection)
Checkboxes (Terms & Conditions)
Date Picker validation
File Upload (Format & Size validation)
Buttons, Links, and Search Bar behavior

**Integration Testing**
Login → Home Page navigation
Doctor search → Profile page redirection
Profile → Appointment booking flow
Booking → Payment → Confirmation
Appointment history update
Cancellation & Refund flow

**System Testing**
End-to-end appointment booking
Appointment ID generation
Notification (Email/SMS reminder)
Product ordering
Logout verification

**Test Case Structure**

Clear test scenarios
Covers positive & negative flows
Test Case IDs:
-**Integration:** TC-IT01 – TC-IT05
-**System:** TC-ST01 – TC-ST05
-**Defect Reports:** DR-01, DR-02
